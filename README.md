# Solar System Explorer

A React + Three.js single-page app for exploring realistic solar system objects and their gravitational interactions.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

This project is a Vite SPA and deploys to Vercel with zero extra config. Connect the repo in the Vercel dashboard, or:

```bash
npx vercel
```
